# Tutorials

Start here if you want a guided path through the package in order.

1. [01_getting_started_age_structured_models.qmd](01_getting_started_age_structured_models.qmd) - use this first for the core age-structured SIR/SEIR workflow, model setup, contact matrices, and basic simulation output.
2. [02_custom_models_and_cumulative_flows.qmd](02_custom_models_and_cumulative_flows.qmd) - use this next when you need custom compartment structures, `CompartmentModel()`, or cumulative flow tracking.
3. [03_demography_and_coupling.qmd](03_demography_and_coupling.qmd) - use this when you want demographic turnover, annual-cohort coupling, or coupled epidemic-demography workflows.
4. [04_stochastic_simulation.qmd](04_stochastic_simulation.qmd) - use this for fixed-population stochastic sample paths, event logs, and cumulative stochastic flows.
5. [05_demography_only_and_diagnostics.qmd](05_demography_only_and_diagnostics.qmd) - use this when you want standalone demographic simulation, diagnostics, or residual checks.
6. [06_external_data_and_case_study_scaffolds.qmd](06_external_data_and_case_study_scaffolds.qmd) - use this for observed-case mapping, optional external-data adapters, and realistic case-study scaffolds.

The tutorials are ordered from the simplest model setup through stochastic,
demographic, and external-data workflows.
