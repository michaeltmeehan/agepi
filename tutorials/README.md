# Tutorials

Start here if you want a guided path through the package in order.

1. [01_getting_started_age_structured_models.qmd](01_getting_started_age_structured_models.qmd) - use this first for the core age-structured SIR/SEIR workflow, model setup, contact matrices, and basic simulation output.
2. [02_custom_models_and_cumulative_flows.qmd](02_custom_models_and_cumulative_flows.qmd) - use this next when you need custom compartment structures, `CompartmentModel()`, or cumulative flow tracking.
3. [03_demography_and_coupling.qmd](03_demography_and_coupling.qmd) - use this when you want demographic turnover, annual-cohort coupling, or coupled epidemic-demography workflows.

The tutorials are ordered from simplest model setup to the more specialised demographic and coupling paths.
